# Perfect Body · วิธีติดตั้งบน iPhone

## 1. อัปขึ้น GitHub (ทำในบัญชีเดิมของ FARM)
1. github.com/new → ชื่อ repo: `perfectbody` → Public → Create repository
2. กด "uploading an existing file" → เลือก 8 ไฟล์: index.html, three.min.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable.png, apple-touch-icon.png → Commit changes
3. Settings → Pages → Deploy from a branch → main / (root) → Save
4. รอ 1–2 นาที ได้ลิงก์ https://wk-007-101.github.io/perfectbody/

## 2. ติดตั้งบน iPhone ของพี่สาว
1. เปิดลิงก์ใน **Safari** (ต้องเป็น Safari เท่านั้น)
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → เลื่อนหา **เพิ่มไปยังหน้าจอโฮม** → เพิ่ม
3. เปิดจากไอคอน Perfect Body บนหน้าจอโฮมทุกครั้ง

## ข้อควรรู้
- ข้อมูลอยู่ใน iPhone เครื่องนั้นเท่านั้น ถ้าลบไอคอนแอปหรือเปลี่ยนเครื่องจะหาย → เพิ่มเติม → ตั้งค่า & สำรอง → สำรองข้อมูลทุกสัปดาห์ เก็บไฟล์ใน iCloud Drive
- อัปเดต: อัป index.html ใหม่ทับใน repo เดิม แล้วปิด-เปิดแอป 2 รอบ
